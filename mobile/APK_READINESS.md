# Mirai: подготовка следующего Android APK

Проверено 2026-10-09. Это подготовка исходников, не подтверждение готовности внешнего сервера или подписанного APK.

## Что исправлено

- Запоздалый ответ входа не сохраняет токены после выхода или более нового входа.
- HTML-ошибка шлюза при входе отображается понятным сообщением.
- Загрузка истории и ответы чата отбрасываются после смены/очистки переписки; подтверждённое сообщение убирается из ожидающих даже при последующей ошибке загрузки истории.
- Чтение, сохранение и очистка очереди одного аккаунта выполняются последовательно, без потерянных частей сообщения при одновременной очистке.
- Ошибка очистки локальных данных после удаления аккаунта не блокирует выход; пользователь получает предупреждение об оставшихся локальных данных.
- Убран вывод учебного профиля и прогресса в консоль.
- Совместимые обновления shell-quote 1.12.0, compression 1.8.2, source-map-js 1.2.2.

## Перед сборкой

Из каталога mobile:

```sh
npm run apk:check
```

Команда проверяет типы, линтер, тесты и экспорт Android/Hermes. Использует API URL профиля preview из eas.json; локальный .env не переопределяет его. Экспорт не является APK.

Для запуска подписанной облачной сборки:

```sh
npm run apk:build
```

Команда сначала повторяет проверки, затем запускает EAS Android preview. EAS_NO_VCS и EAS_PROJECT_ROOT ограничивают архив каталогом mobile; .easignore исключает секреты, native-каталоги, тесты и результаты экспорта. Сборка использует существующий проект/ключ подписи и увеличивает удалённый versionCode. Нужен вход в EAS и доступная квота; платный тариф автоматически не выбирается.

## Результаты и ограничения

- Сервер: 54 теста SQLite прошли 2026-10-09. PostgreSQL в этом прогоне не проверялся.
- Мобильные регрессионные тесты: 21, включая отменённый вход и конкурентные операции очереди.
- TypeScript, ESLint и Android export проверяются командой выше.
- Security update: UUID and URL decoder upgraded; braces/node-forge have reproducible local mitigations and regression tests. Raw audit: 19 high entries without devDependencies (21 with devDependencies), two underlying advisories. See SECURITY_DEPENDENCIES.md for scope and remaining review requirements.
- Облачная APK-сборка в этом этапе не запускалась. Старый APK не содержит этих исправлений.
- URL preview всё ещё https://mirai-9wx9.onrender.com. Новая серверная версия не развёрнута; наличие DATABASE_URL в Render не доказывает доступность схемы/API.
- Письма регистрации/восстановления не настроены. Домен отложен владельцем. Проверка почты не отключалась.
- До приглашения тестировщиков: развернуть сервер с миграциями, проверить готовность БД и реальные письма/AI; установить новый APK на физический Android.

## Ручной прогон на телефоне

1. Регистрация, подтверждение почты, вход; неверный/просроченный код.
2. Чат и обучение; обрыв сети во время отправки, перезапуск, повтор без двойного ответа/XP.
3. Очистка истории при загрузке: старые сообщения не возвращаются.
4. Выход и другой аккаунт: нет чужой истории или настроек.
5. Сохранение языка/режима после перезапуска.
6. Сброс пароля и удаление тестового аккаунта.
7. Проверка разрешений/доставки push отдельно: требует настроенного обработчика и FCM.
