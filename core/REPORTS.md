# Жалобы на AI-ответы

Пользователь нажимает Report reply под ответом, выбирает причину и подтверждает отправку. Приложение сообщает об успехе только после ответа сервера `received`; при сбое форму можно отправить повторно.

Сервер принимает только ID сохранённого assistant-сообщения текущего пользователя. Текст берётся из базы, не из клиентского запроса. Повторная отправка не создаёт дубликат. Есть ограничение частоты запросов. Жалобы сохраняются после очистки чата (об этом предупреждает форма) и удаляются при удалении аккаунта. Публичного API чтения жалоб нет.

## Выпуск
Сначала развернуть сервер с миграцией 0005_content_reports, затем выпустить новую APK/AAB. На старом сервере отправка жалоб не работает; APK 8 этой функции не содержит. Старые клиенты продолжают работать: assistant_message_id — дополнительное поле ответа /chat.

## Разбор разработчиком
На доверенном сервере/рабочем месте с настроенным DATABASE_URL:

- `python -m core.review_reports list` — до 100 самых старых непросмотренных жалоб; без текстов и email.
- `python -m core.review_reports show MESSAGE_UUID` — выбранная причина и текст ответа. Приватный вывод: не вставлять в публичные логи, задачи или карточку магазина.
- `python -m core.review_reports resolve MESSAGE_UUID` — отметить рассмотренной после проверки и необходимых действий.

Просмотр выполняется вручную. Автоматические уведомления и панель модерации не настроены. Перед публичным запуском назначить ответственного и периодичность разбора, согласовать срок хранения и внести жалобы в опубликованную политику приватности/Data safety. Функция жалоб сама по себе не гарантирует соответствия всем требованиям Google Play.
